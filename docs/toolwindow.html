Total IDE Visibility

Dedicated 4-Tab Tool Window

A unified command center docked at the bottom of your IDE. Monitor Git operations in real time, inspect assigned tasks, visualize branch topologies, and track CI/CD builds.

Live Output & Telemetry

Real-Time Execution Logs

Never guess what Git commands are running under the hood. The Logs tab displays every single Git operation asynchronously executed by the plugin, complete with exact parameters, stdout, stderr, and exit codes.

  • ✓ Customizable Typography: Choose your favorite font family and adjust font size directly inside the tool window settings.
  • ✓ Multi-Repository Tagging: Clear repository prefix tags in multi-root workspaces to identify which repository triggered each command.
  • ✓ Live Status Indicator: Animated spinner on the tool window tab whenever background tasks are actively running.

Topological Visualization

Interactive Visual Flow Diagram

See your active branch state at a glance. The Flow tab generates an interactive topological map of all local and remote branches in your Git repository.

  • ● Main: Blue production line with release tags.
  • ● Develop: Emerald green integration line.
  • ● Features: Amber branches showing current work in progress.
  • ● Releases & Hotfixes: Cyan and red tracks with convergence markers.

Integrated Task Server

Issues & Tasks Inspector

Browse assigned tickets from Jira, GitHub, GitLab, or Redmine directly within the IDE. View ticket descriptions, recent comments, and start branches with one click.

  • ✓ Side-by-Side Dual Pane: Task list on the left with detailed rich inspector on the right.
  • ✓ Instant Branch Creation: 'Start Feature' or 'Start Hotfix' buttons directly inside ticket details.
  • ✓ Quick Browser Shortcut: Click to jump straight to the issue URL in your default browser.

Continuous Integration

CI/CD Pipeline Monitoring

Stay in your coding zone while tests and deployment jobs execute. The CI/CD tab connects to Jenkins pipelines to give you real-time build telemetry without browser tab switching.

  • ✓ Live Console Streaming: Progressive terminal output streaming with intelligent ANSI color highlighting.
  • ✓ Build Trigger & Status: Trigger new builds upon publishing or finishing branches and observe build status badges.
  • ✓ Secure Authentication: Credentials stored safely using IntelliJ's encrypted PasswordSafe subsystem.
